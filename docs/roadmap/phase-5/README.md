# Phase 5: Advisors mod

This phase builds the separate advisors mod, with read-only advisors, one per victory condition, in their own UI panel.

**Gate.** In playtests over a full game, a player follows an advisor's advice and judges it as good.

## Scope

- Read-only advisor tools
- One advisor personality per victory condition
- Advisor UI panel

# Roadmap

The work runs in six phases. Each phase ends at a gate, a test that must pass before the next phase starts. The MVP is phase 1. Phases 2 to 4 add features in priority order, and phase 5 is the advisors mod.

Each phase is a folder. When work on a phase starts, we break it into step files. See [rules/docs.md](../rules/docs.md#roadmap).

| Phase | Gate | Status |
| --- | --- | --- |
| [0: Prove the bridge](phase-0/README.md) | From the bridge, list your cities and move one unit | Done |
| [1: MVP, one agent finishes a game](phase-1/README.md) | One agent plays a full single-player game against the native AI with no manual help | Not started |
| [2: You and several agents](phase-2/README.md) | You play a game against two agents, with at least one reload to an earlier save | Not started |
| [3: Personalities and play quality](phase-3/README.md) | Agents with different sweat levels and personalities play visibly different games | Not started |
| [4: Setup screen, spectating, and release](phase-4/README.md) | A nontechnical user installs, sets up, and watches an agent-only game without editing a file | Not started |
| [5: Advisors mod](phase-5/README.md) | A player follows an advisor's advice over a full game and judges it as good | Not started |

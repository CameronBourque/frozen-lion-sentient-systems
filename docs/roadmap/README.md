# Roadmap

The work runs in seven phases. Each phase ends at a gate, a test that must pass before the next phase starts. Phase 1 serves the game as MCP tools that an outside client can play through, and the MVP is phase 2. Phases 4 to 6 add features in priority order, and phase 7 is the advisors mod.

Each phase is a folder. When work on a phase starts, we break it into step files. See [rules/docs.md](../rules/docs.md#roadmap).

| Phase | Gate | Status |
| --- | --- | --- |
| [0: Prove the bridge](phase-0/README.md) | From the bridge, list your cities and move one unit | Done |
| [1: Agent tools over MCP](phase-1/README.md) | From Claude Code, play 10 turns of a single-player game through the MCP server, with a `reason` on every action | Done |
| [2: MVP, one agent finishes a game](phase-2/README.md) | One agent plays a full single-player game against the native AI with no manual help | Not started |
| [4: You and several agents](phase-4/README.md) | You play a game against two agents, with at least one reload to an earlier save | Not started |
| [5: Personalities and play quality](phase-5/README.md) | Agents with different sweat levels and personalities play visibly different games | Not started |
| [6: Setup screen, spectating, and release](phase-6/README.md) | A nontechnical user installs, sets up, and watches an agent-only game without editing a file | Not started |
| [7: Advisors mod](phase-7/README.md) | A player follows an advisor's advice over a full game and judges it as good | Not started |

# Core mod choices

The calls that list the legal options for each choice, and the tiles where a district or a wonder can go. Part of the [core mod](README.md).

## Choices

`SentientSystems_GetChoices(playerID)` returns the legal options for each discrete choice as JSON, in a call of its own, so the agent reads them only when it decides. They include production and gold, faith, and tile purchases for each city, techs, civics, policies, and the options for each other end-turn blocker. An option lists what its screen shows, such as turns to complete, boost status or the boost requirement, resource requirements, and prerequisites. Tile purchases list the tiles to buy, and the tiles where a district or a wonder can go come from the placement call. An item the screen greys out is listed with the screen's reason, in the game's language, and with its text key where the game gives one. Each blocker in the state names the choice that resolves it. `SentientSystems_GetChoices` is in `Scripts/Choices/SentientSystemsCore_Choices.lua`, which the UI script loads with `include`, and the bridge reads it through the stash. Each choice has its own file in `Scripts/Choices/`, such as `SentientSystemsCore_ChoicesProduction.lua`, which defines one global, such as `SentientSystems_GetProductionChoices(player)`. The choices file loads each one and puts them together. The production choice counts the tiles from the placement file to decide what the panel greys out. The calls are in [findings/choices/choices.md](../../../findings/choices/choices.md), those for the government and policies in [findings/choices/government.md](../../../findings/choices/government.md), and those for religion in [findings/choices/religion.md](../../../findings/choices/religion.md), those for envoys in [findings/choices/city-states.md](../../../findings/choices/city-states.md), those for great people in [findings/choices/great-people.md](../../../findings/choices/great-people.md), those for captured cities in [findings/choices/captured-cities.md](../../../findings/choices/captured-cities.md), those for spies in [findings/choices/spies.md](../../../findings/choices/spies.md), and those for artifacts in [findings/choices/artifacts.md](../../../findings/choices/artifacts.md), those for governors in [findings/state/governors.md](../../../findings/state/governors.md), those for dedications in [findings/choices/dedications.md](../../../findings/choices/dedications.md), those for emergencies in [findings/choices/emergencies.md](../../../findings/choices/emergencies.md), and those for the World Congress in [findings/choices/world-congress.md](../../../findings/choices/world-congress.md). The shape of each choice is in the schemas in [packages/core/bridge/src/choices/](../../../../packages/core/bridge/src/choices/).

## Placement

`SentientSystems_GetPlacement(playerID, cityID, type)` in `Scripts/Placement/SentientSystemsCore_Placement.lua` returns where a city can place one district or wonder as JSON, in a call of its own, as the placement view shows the tiles once the player picks one. The UI script loads the file, and the bridge reads the call through the stash. It raises an error for an ID with no player or city, and for a type that isn't a district or a wonder. The calls are under **Placement tiles** in [findings/choices/choices.md](../../../findings/choices/choices.md). The shape is in [packages/core/bridge/src/placement/](../../../../packages/core/bridge/src/placement/).

## Decisions

| Decision | Reason |
| --- | --- |
| The choices list the legal options for discrete choices, and the placement call the tiles for a district or a wonder | Saves wasted calls. Those tiles are few, so a list beats guessing. Moves and attacks have too many targets to list, so they return failure reasons instead |
| The tiles for districts and wonders are a call of their own, for one district or wonder | Tiles were about two thirds of the production choice, and a mid-game empire would send about 100 KB of them. The agent needs the tiles only for the one item it places, as a player sees them only after picking one |
| The choices are a call of their own, not part of the state | Production options for every city are large, and the agent needs them only when it decides. Keeping them out of the state keeps each turn's context small |
| A greyed-out option carries the screen's own text | It needs no upkeep and matches what a player reads. Our own codes would need a mapping for every reason, including those from DLC and mods. If agents misread the text, codes come next |

# Agent players mod

Turns a human player slot into an LLM agent. It depends on the core mod and reaches the game only through the core API.

Design: [docs/design/agents/](../../docs/design/agents/README.md).

The personality and sweat level files live in the bridge, in `packages/core/bridge/knowledge/`. See [knowledge-files.md](../../docs/design/knowledge-files.md#file-layout).
